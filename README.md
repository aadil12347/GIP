# GIP Program Website Clone

A premium, fully responsive local dashboard clone of the TikTok Gaming Incentive Program (GIP) Course website.

## Features
- **Modern Dark Theme**: Cyberpunk-inspired aesthetic featuring HSL custom styling and sleek scrollbars.
- **Responsive Layout**: Splitted left navigation sidebar for desktop and collapsible hamburger menu for mobile.
- **Embedded Videos**: Custom wrappers containing embedded Google Drive lectures.
- **Interactive Checklists**: 4-day Account Setup & Warm Up and 1k Followers Roadmap lists with state-saving persistence in the browser (`localStorage`).
- **Premium Services & Softwares**: Detailed catalog grid for requesting website subscriptions, organic growth followers, automation bots, and paid tools.

## How to Run Locally
1. Launch the local web server:
   ```bash
   python start_server.py
   ```
2. The script will automatically open the site in your default browser at [http://localhost:8000](http://localhost:8000).
